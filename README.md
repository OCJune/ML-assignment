# 몬테카를로 vs Q-러닝 성능 비교 분석 프로젝트

이 프로젝트는 `environment.py`에 정의된 **Cliff Walking(절벽 걷기)** 미로 환경에서 강화학습의 두 가지 대표적인 알고리즘인 **몬테카를로(Monte Carlo)**와 **Q-러닝(Q-Learning)**의 학습 성능을 비교 분석합니다.

## 1. 분석 전략

본 프로젝트는 두 알고리즘의 공정한 성능 비교를 위해 다음과 같은 전략을 따릅니다.

### 1.1 동일한 모델 아키텍처 (DNN)
두 에이전트 모두 Keras를 사용하여 동일한 구조의 심층 신경망을 사용합니다.
- **Input**: 48차원 원-핫 벡터 (4x12 그리드 상태)
- **Hidden Layers**: 2개의 Dense 레이어 (각 64 노드, ReLU 활성화 함수)
- **Output**: 4개의 행동 가치 (상, 하, 좌, 우 / Linear 활성화 함수)

### 1.2 알고리즘별 학습 방식의 차이
- **몬테카를로(MC) 에이전트**: 에피소드가 완전히 종료된 후, 수집된 전체 경로의 보상 합($G_t$)을 타겟으로 하여 신경망을 업데이트합니다. (High Variance, No Bias)
- **Q-러닝 에이전트**: 매 스텝마다 시간차(TD) 타겟($r + \gamma \max Q'$)을 계산하여 실시간으로 신경망을 학습합니다. (Low Variance, Potential Bias)

### 1.3 성능 평가 지표
- **Total Reward per Episode**: 학습이 진행됨에 따라 에피소드당 얻는 총 보상의 상승 곡선 분석.
- **Steps to Goal**: 최단 경로(13스텝)에 얼마나 빠르게 수렴하는지 분석.
- **Cliff Falls**: 학습 과정 중 절벽으로 추락하여 페널티(-100)를 받는 빈도 측정.

## 2. 설치 및 실행 방법

### 2.1 환경 구축
프로젝트 실행에 필요한 라이브러리를 설치합니다. (Python 3.x 환경 권장)
```bash
pip install -r 팀플/environment.txt
```

### 2.2 통합 비교 실행 (권장)
두 알고리즘을 동시에 학습시키고 비교 그래프(`learning_comparison.png`)를 생성합니다.
```bash
python 팀플/compare_training.py
```

### 2.3 개별 알고리즘 실행
각 알고리즘의 학습 과정을 개별적으로 확인하려면 다음 스크립트를 실행합니다.
- **몬테카를로**: `python 팀플/run_mc.py`
- **Q-러닝**: `python 팀플/run_qlearning.py`
